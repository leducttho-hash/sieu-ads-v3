Đọc Sheet công ty bằng quyền Google của bạn

Kiểm tra kết nối trước khi đưa vào Đồng bộ Kho. Google Sheet chỉ đọc vùng A1:T20. File Excel được tải cả workbook vào bộ nhớ (tối đa 20 MB), rồi chỉ hiển thị A1:T20 của tab bạn nhập. Bản thử không cập nhật Catalog hay cấu hình Siêu Ads.

1. Kết nối Google

Đang tải thư viện xác thực Google…

Nút đầu xin quyền spreadsheets.readonly để đọc Google Sheets. Nút Kết nối Google + đọc Excel trên Drive xin thêm drive.readonly, cho phép đọc/tải các file trên Drive mà tài khoản có quyền truy cập. Bản thử chỉ gọi file bạn nhập, kiểm tra quyền tải trước khi lấy Excel, không sửa file. Token và nội dung chỉ giữ trong bộ nhớ, không ghi vào bộ nhớ lưu trữ trình duyệt, bản sao lưu hay kho mã. Không cần Client Secret hoặc API key.

2. CĐ Tiểu học

Đọc Excel theo tên tab; không suy ra từ gid. Theo file bạn cung cấp: Caption · Header hàng 3 · Mã B / Body C / Media D / MIX F / Page E.

3. MESS Gia sư

Đọc Excel theo tên tab; không suy ra từ gid.
Tạo Client ID một lần
  1. Trong Google Cloud, tạo dự án và bật Google Sheets API.
  2. Google Auth Platform → Branding: đặt tên Siêu Ads thử đọc Sheet và email hỗ trợ. Audience: nếu dùng nhiều Gmail, chọn External, để chế độ Testing, thêm đúng email được cấp quyền Sheet vào Test users. Nếu công ty quản lý Google Workspace, có thể cần quản trị viên cho phép ứng dụng.
  3. Data Access: thêm https://www.googleapis.com/auth/spreadsheets.readonly. Để đọc Excel, bật thêm Google Drive API và thêm https://www.googleapis.com/auth/drive.readonly. Dùng tiếp Client ID hiện có.
  4. Clients → Create client → Web application. Authorized JavaScript origins: https://leducttho-hash.github.io. Không thêm đường dẫn /sieu-ads-v3/. Bản thử dùng popup, không cần Redirect URI.
  5. Dán Client ID vào ô trên. Mở bản thử qua HTTPS GitHub Pages; không mở bằng file://. Bấm kết nối và chọn đúng tài khoản đã có quyền đọc Sheet.
  6. Dán hai link, bấm đọc thử từng file. Chỉ sau khi cả hai đọc đúng tab và dữ liệu thì mới tích hợp vào Đồng bộ Kho.
